### Planned

## [1.0.0] - 2026-05-29

### Added

- Initial release of Advanced Prompts Factory
- RepoArchitect Pro v2.0 meta-prompt with stack-aware intelligence
- Complete documentation structure (README, CONTRIBUTING, SECURITY)
- GitHub issue templates for bug reports and feature requests
- Pull request template for standardized contributions
- CI/CD workflows for markdown linting and link checking
- Dependabot configuration for automated dependency updates
- PowerShell automation scripts (Make.ps1)
- Comprehensive architecture documentation
- Usage examples and prompts index
- Bilingual EN/FR support throughout documentation

### Stack Support (RepoArchitect Pro v2.0)

- PowerShell 7.6+ projects
- Node.js 18+ projects
- Python 3.9+ projects
- Nix/NixOS projects
- Bash/Shell scripts
- Multi-stack detection and adaptation

### Project Types Support

- CLI tools
- Libraries/Packages
- Web applications
- REST APIs
- Script collections
- Configuration/dotfiles repositories

### Features

- Zero-placeholder generation guarantee
- Silent stack analysis (Phase 0)
- Real, executable code in all generated files
- 15+ files per project generation
- markdownlint compliance enforcement
- Conventional Commits support
- Security policy and reporting process

### Documentation

- Detailed README with bilingual content
- Contributing guidelines with coding standards
- Security policy with vulnerability reporting process
- Code of Conduct based on Contributor Covenant
- Architecture diagrams and technical documentation
- Troubleshooting guides and FAQs

### Infrastructure

- GitHub Actions CI/CD pipeline
- Markdown linting with markdownlint-cli2
- Link checking automation
- Metadata validation for prompts
- Automated release workflow (planned)

## [0.1.0] - 2026-05-29 (Internal)

### Added

- Project structure and repository setup
- Initial meta-prompt concept (RepoArchitect Pro v1.0)
- Basic documentation framework
- Proof of concept for stack-aware generation

### Changed

- Migrated from generic templates to stack-specific generation
- Improved placeholder elimination strategy
- Enhanced bilingual documentation approach
